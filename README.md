# 🕉️ Dev Darshan - Smart Crowd Management System

## Overview
Dev Darshan is a comprehensive crowd management system for pilgrimage sites that helps devotees book darshan slots, view real-time crowd levels, and get intelligent routing suggestions.

## Features

### For Devotees
- **Virtual Queue Booking**: Book darshan slots with QR code generation
- **Live Crowd Dashboard**: Real-time crowd levels for entrance, temple area, and parking
- **Intelligent Routing**: Dynamic routing suggestions based on crowd conditions
- **Booking Management**: View, manage, and cancel bookings
- **Priority Queue**: Special access for elderly and disabled persons

### For Admins
- **Crowd Control Panel**: Manual crowd level updates
- **Booking Management**: View and manage all bookings
- **Routing Control**: Push real-time routing messages to users

## Tech Stack
- **Frontend**: React.js with Tailwind CSS
- **Backend**: Firebase (Auth, Firestore)
- **Charts**: Chart.js
- **QR Codes**: qrcode.react
- **Animations**: Framer Motion
